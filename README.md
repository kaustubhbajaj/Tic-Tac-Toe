#  Tic Tac Toe Game

A simple and interactive **Tic Tac Toe game** built using **HTML, CSS, and JavaScript.
This project helped me understand **DOM manipulation, event handling, and basic game logic** in JavaScript.

---

## 🚀 Features
- Two-player game (X vs O)
- Turn-based gameplay
- Prevents overwriting of moves
- Sound effects on each turn
- Displays current player's turn
- Clean and responsive UI

---

## 🛠️ Technologies Used
- **HTML** – Structure of the game
- **CSS** – Styling and layout
- **JavaScript** – Game logic and interactivity

---

## 🧠 Game Logic (Overview)
1. Each box listens for a click event
2. On click, the box is checked if empty
3. Current player's symbol (X/O) is inserted
4. Turn switches after every valid move
5. Game checks for a winning condition after each turn
